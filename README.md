# Autoescuelas PREMIUM Alicante (Gran Vía)

Sitio web oficial de **Autoescuelas PREMIUM Alicante** — Centro de Formación Vial y del Transporte Profesional en Av. Pintor Xavier Soler, 1, Local 3, 03015 Alicante.

## Estructura del Proyecto

```text
.
├── index.html                    # Landing page oficial de alta conversión
├── vercel.json                   # Configuración de seguridad HTTP, cache y URLs limpias
├── dossie_autoescola.md          # Dossier estratégico y catálogo oficial DGT
└── assets/
    └── images/
        ├── brand/                # Logotipo oficial y favicon
        ├── hero/                 # Fotografía de fachada principal
        ├── facilities/           # Recepción y aula informatizada
        └── students/             # Galería real de alumnos aprobados y flota
```
